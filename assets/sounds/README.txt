حط هنا ملفات الصوت دي (بنفس الأسماء عشان الكود يلاقيها):

- ambience.mp3   -> صوت خلفية عام مخيف (طقطقة نار / جو عام) يتكرر (loop)
- whispers.mp3   -> همس خفيف، بيتكرر هو كمان
- break.mp3      -> صوت حاجة بتتكسر، بيشتغل لحظة الدخول (مرة واحدة)
- unlock.mp3     -> صوت فتح قفل، بيشتغل لما الليدر يفتح تاسك (مرة واحدة)
