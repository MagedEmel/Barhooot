# عشيرة الظلام - دليل التشغيل

## 1) هيكل الملفات
```
clan-site/
├── index.html        ← صفحة اختيار الاسم + رسالة الترحيب المرعبة
├── user.html          ← صفحة اليوزر العادي (المؤشر)
├── leader.html        ← صفحة الليدر (المؤشر + المهام المقفولة)
├── admin.html         ← لوحة تحكم الأدمن
├── css/main.css        ← الثيم العام (أحمر/أسود/نار)
├── js/
│   ├── firebase-config.js  ← اتصال فاير بيز (لازم تعدّل فيه)
│   ├── version-check.js     ← التحديث الأوتوماتيك من GitHub
│   ├── landing.js
│   ├── user.js
│   ├── leader.js
│   └── admin.js
└── assets/sounds/      ← هنا تحط ملفات الصوت (راجع README.txt جواها)
```

## 2) إعداد فاير بيز (Firestore)
1. روح على https://console.firebase.google.com وسوي مشروع جديد.
2. من القائمة الجانبية فعّل **Firestore Database** (ابدأ في وضع Test mode مؤقتاً).
3. من Project settings > General > Your apps، ضيف "Web app" وانسخ بيانات `firebaseConfig`.
4. حط البيانات دي في ملف `js/firebase-config.js` بدل القيم الفاضية.

### الكولكشنز المطلوبة (تسويها يدوي من Firebase Console):

**users** (كل دوكيومنت = شخص):
```
name: "احمد"
group: "الذئاب الحمراء"
role: "user"      // أو "leader" أو "admin"
```

**groups** (الـ id بتاع الدوكيومنت = نفس اسم المجموعة):
```
score: 0
```

**config** → دوكيومنت واحد اسمه **settings**:
```
greenThreshold: 10
redThreshold: -10
adminPassword: "اكتب_باسورد_قوي_هنا"
shapes: [
  { label: "نصر صغير", value: 5 },
  { label: "نصر كبير", value: 15 },
  { label: "عقاب", value: -10 }
]
```

**tasks** (تقدر تضيفها من لوحة الأدمن نفسها بعد التشغيل، مش لازم تسويها يدوي):
```
title: "اسم المهمة"
password: "1234"
content: "النص أو الموقع اللي يظهر بعد الفتح"
order: { "اسم العشيرة 1": 1, "اسم العشيرة 2": 3 }   // ترتيب مختلف لكل عشيرة
```
> `order` بقى Map (مش رقم واحد بس)، فكل عشيرة تقدر يكون ليها ترتيب ظهور مختلف
> لنفس المهمة. لو عشيرة معينة مالهاش ترتيب محدد جوه المابة دي، المهمة هتظهر
> ليها في آخر القايمة تلقائياً. تقدر تتحكم في كل ده من تاب "المهام" في لوحة
> الأدمن، مفيش حاجة محتاجة تعملها يدوي في Firestore Console.

> ملحوظة أمان: الباسوردات (باسورد الأدمن وباسوردات المهام) متخزنة كـ plain text
> في Firestore، وبما إن السايت كله front-end ثابت (مفيش سيرفر)، أي حد فاهم
> ممكن يشوفها لو دخل الـ console بتاعه وقرا الداتا مباشرة من فاير بيز.
> ده طبيعي ومتوقع لمشروع بالشكل ده (لعبة/تجربة بين أعضاء عشيرة)، لكن لو
> حسّاس بخصوصية الباسوردات أكتر من كذا، تقدر تستخدم Firestore Security Rules
> (تحت) عشان تقلل الوصول.

### قواعد أمان مقترحة (Firestore Rules)
من Firebase Console > Firestore > Rules:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if true; // مفتوح بدل Authentication لأن السايت بدون تسجيل دخول حقيقي
    }
  }
}
```
ده بيخلي أي حد عنده اللينك بتاع السايت يقدر يقرا ويكتب في الداتا (لأن مفيش
نظام تسجيل دخول حقيقي/Authentication). لو عايز تأمين أقوى، ينفع نضيف
Firebase Authentication بعدين، قولي لو عايز كذا.

## 3) رفع السايت على GitHub Pages
1. اعمل ريبو جديد على GitHub، ورفع فيه كل محتوى مجلد `clan-site`.
2. من Settings > Pages، اختار البرانش (main) والمجلد (root) وحفظ.
3. السايت هيبقى متاح على:
   `https://YOUR_USERNAME.github.io/YOUR_REPO/`

## 4) تفعيل التحديث الأوتوماتيك (من غير Hard Refresh)
افتح `js/version-check.js` وغيّر السطرين دول لاسمك الحقيقي:
```js
const GH_OWNER = "YOUR_GITHUB_USERNAME";
const GH_REPO  = "YOUR_REPO_NAME";
```
بعد كذا، أي مرة تعمل push لكومنت جديد على GitHub، السايت (المفتوح عند أي حد)
هيتشيك كل 25 ثانية، وأول ما يحس إن فيه كومنت جديد هيظهرله شريط فوق
"ظهر تحديث جديد" وهيعمل ريفريش لوحده تلقائي خلال ثواني، أو لما يدوس عليه.

## 5) ملفات الصوت
حط ملفاتك في `assets/sounds/` بالأسماء المكتوبة في `assets/sounds/README.txt`.
المتصفحات بشكل عام مش بتسمح بتشغيل صوت أوتوماتيك من غير ضغطة من المستخدم،
فالصوت في `index.html` بيبدأ يشتغل لما المستخدم يدوس "ادخل إن كنت تجرؤ" (وده
كويس لأنه بيزيد من تأثير اللحظة المرعبة). في باقي الصفحات (user/leader/admin)
حطينا `autoplay` بس ممكن المتصفح يمنعه لو مفيش تفاعل سابق من المستخدم — في
الحالة دي الصوت هيبدأ لما يضغط أي زرار في الصفحة.

## 6) تسجيل الدخول والصلاحيات
- مفيش Authentication حقيقي، النظام بيعتمد على اختيار الاسم بس (Session في المتصفح).
- لو عايز تمنع أي حد من كتابة اسم مش بتاعه ويدخل بدور غيره، الحل الوحيد
  المضمون هو إضافة Firebase Authentication (إيميل/باسورد لكل شخص)، وده
  ممكن نضيفه في خطوة تالية لو احتجته.
- صفحة الأدمن فيها بوابة باسورد إضافية (`config/settings.adminPassword`)
  حتى لو حد عرف يدخل admin.html مباشرة.

## 7) حاجات ممكن تتضاف بعدين (قولّي لو عايز أي منها)
- نظام تسجيل دخول حقيقي (Firebase Auth) بدل الاسم بس.
- Animation/Sound أكتر تخصيصاً لكل حدث (مثلاً صوت مختلف عند زيادة/خصم نقاط).
- صفحة "سجل العمليات" (Log) تسجل كل نقطة اتضافت/اتخصمت وامتى ومين عملها.
- دعم لغات متعددة بدل العربي فقط.
